# 对象校准

内部 ID：`object-calibration`

## 适用

当“用户、客户、团队、合作方、受影响者”等对象被混在一起，或内部想象替代了现实对象证据时使用。

## 不适用

对象、受影响方和现实证据入口已经清楚时不使用；不要把它变成所有议题的强制调查步骤。

## 输入

- 暂定真实目的；
- 涉及的对象；
- 谁获得收益、谁承担代价、谁实际响应；
- 当前已有的现实证据。

## 过程

1. 分开服务对象、受影响对象、决定者、使用者、付费者和代价承担者；只保留本议题真实存在的角色。
2. 检查这些角色是否被一个含混标签替代。
3. 区分用户已观察到的行为与对对象需求、动机的推测。
4. 识别哪一类对象的哪个可观察结果最可能改变决定。
5. 收敛为一个最小证据入口，不扩展成全面调研。

## 独特产出

对象关系、当前证据错位和一个会改变判断的现实证据入口。

## 组合边界

与基础分析的证据分层部分重叠，只有对象本身不清时才提供增量。若问题是资源或阶段而非对象，不使用本卡。
