# 证据闭环

内部 ID：`evidence-loop`

## 适用

事项已经执行并产生真实结果、成本或偏差，需要判断继续、调整、暂停或停止时使用。

## 不适用

尚未开始、没有现实结果、正在紧急处置，或只有情绪归因而没有可观察证据时不使用。

## 输入

- 原真实目的、原判断和成功标准；
- 实际结果、投入和意外后果；
- 执行过程、资源和外部条件变化。

## 过程

1. 把原目标、假设和成功标准与实际结果放在同一尺度比较。
2. 区分偏差主要来自判断错误、执行偏差、资源错配还是条件变化。
3. 同时检查收益、成本、机会成本和意外后果，不只看显眼指标。
4. 识别应保留、修改或停止的核心假设，而不是批评个人。
5. 形成一个复判阈值，支持继续、调整、暂停或停止。

## 独特产出

偏差机制、应保留或改变的判断依据，以及复判阈值。

## 组合边界

与 `stage-fit` 重叠时，本卡优先解释已经发生的结果，阶段变化只是可能原因之一。不得扩展成多项整改清单；阶段 B 仍只给一个有界下一步。
