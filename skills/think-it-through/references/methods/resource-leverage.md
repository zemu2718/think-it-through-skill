# 资源支点

内部 ID：`resource-leverage`

## 适用

多个方向竞争同一有限资源、供给或关键依赖限制选择，或资源被平均铺开导致没有方向形成证据时使用。

## 不适用

资源充足且任务单一，或真正服务的对象尚未校准时不使用。

## 输入

- 可用时间、资金、能力、渠道和关系资源；
- 关键依赖和供给上限；
- 当前投入方向及其结果。

## 过程

1. 区分可自由分配资源、不可替代依赖和必须维持的保底能力。
2. 找出看似亮眼但无法持续、供给或增长的结果。
3. 识别一个能支持下一阶段、可验证且可持续的关键支点。
4. 明确主投入、保底和暂缓方向，但不生成并行行动清单。
5. 设定成本/时间上限和触发资源重配的结果阈值。

## 独特产出

关键支点、保底能力、暂缓方向和资源重配阈值。

## 组合边界

本卡改变资源排序与承诺边界，不负责完整执行路线。阶段 B 仍只给一个现实实验，不能把主投入、保底和暂缓各写成一项任务。
