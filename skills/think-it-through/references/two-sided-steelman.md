# 双向钢人

双向钢人的目标不是制造正反各半，而是让当前倾向与最强竞争方向在相近证据标准下接受检验，暴露结论依赖的前提。

## 确定两个方向

围绕同一个决策问题构造：

- **当前倾向的最强论证**；
- **反对当前倾向，或支持最强替代方向的最强论证**。

常见映射：

| 议题形态 | 两个方向 |
| --- | --- |
| 明确想法或计划 | 支持该想法 vs 反对它或支持最强替代路径 |
| A/B 选择 | A 的最强论证 vs B 的最强论证 |
| 开放困惑 | 主导解释 vs 最强竞争解释 |
| 结果异常 | 主导原因假设 vs 最强替代原因假设 |
| 已执行事项 | 继续或调整 vs 暂停或停止 |

替代方向必须理解用户真实目的。不要挑选容易反驳、但不能服务该目的的稻草人。

## 对称检验

对两方尽量使用相近深度：

1. 在什么条件下成立；
2. 通过什么机制服务真实目的；
3. 哪些已知事实或合理推断支持；
4. 依赖哪些待验证假设；
5. 主要收益、代价和机会成本；
6. 什么证据会削弱它。

对称的是标准，不是结论。若一方证据明显更弱，如实说明，不补造论据，不强行五五开。

## 阶段 A 的产出

将两个方向综合为：

- 最强竞争判断；
- 双方真正分歧；
- 能区分双方的唯一关键变量。

不要逐方写成长篇辩论，不使用人物口吻，不投票。阶段 A 不宣布哪方获胜，不给行动建议，只在唯一问题后停止。

## 常见失败

- **稻草人**：反方只说用户显然已经知道的浅层风险；
- **假平衡**：为了形式对称，把无证据方向写得同样强；
- **问题漂移**：两方服务不同目标，无法比较；
- **重复预演**：反方只罗列执行后风险，没有说明为什么现在不应选择；
- **权威替代**：用名人、流派或“多数专家”替代机制和证据；
- **提前判断**：A 中出现“所以你应该”。
